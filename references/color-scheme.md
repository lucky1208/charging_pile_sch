# EVSE 原理图颜色规范（EVSE-COLOR-SCHEME v1.0）

机器可读：`js/color-scheme.js`（`window.EVSE_COLOR_SCHEME`）。渲染闸门 **G041-LIB-COLOR / LIB-R14** 按白名单自检，出现未登记颜色即阻断导出。

## 依据

- **IEC 60446 / GB/T 6995 识别颜色（强制语义，不得挪用）**：PE 保护接地 = 绿黄（CAD 单色绿，专用）；N 中性线 = 蓝（专用）；交流相线 = 棕/黑/灰（取棕）；直流正 = 红/棕（取红，极性以 DC± 标注区分）。
- **IEC 61082** 不强制简图线色 → 其余类别为项目约定，但不得占用上述识别颜色语义。
- **ISO 3864** 安全红 = 安全器件（急停/消防/浪涌）。

## 约定

1. 设备/元器件外框 = 所属回路色；块底色 = 所属回路浅色（fill.*：ac #fff7ed / dc #fef2f2 / ess #ffedd5 / comm #f5f3ff / ctl #f1f5f9 / aux #ecfeff）。
2. 触点/接线柱 = 白底 + 所属回路色描边；主功率触点加粗描边。
3. 母线线宽 ≥ 3× 普通线宽；N 分线与相线分色（棕/蓝）。
4. 虚线 = 非功率信号（控制灰虚、通信紫虚）。
5. 图例按本表逐行出图并注明依据；图注声明颜色规范版本。
