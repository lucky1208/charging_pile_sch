## 3. 真实浏览器验收

使用本地 Web 默认参数生成 120 kW 国标双枪图，完成以下实际鼠标与键盘操作：

- Shift 点击 `QS1` 与 `QF1` 得到两个高亮对象，主对象以独立颜色显示；Ctrl 点击可切换单个对象；
- 成组拖动两个器件提交一个 `MOVE_OBJECTS` 命令，自动重布 17 条回路，图纸审计保持 `CHECKED`；
- `Ctrl+Z` 一次恢复原始 Drawing IR 哈希 `fnv1a32:1938a898`；
- 网格切换为 10 后用方向键成组微调，自动重布 16 条回路；一次撤销恢复原哈希；
- 顶部对齐提交一个 `ALIGN_DEVICES` 命令并重布 8 条回路；一次撤销恢复原哈希；
- 左→右窗口框选只命中完全包含的 `QF1`；右→左窄框命中所有相交器件与回路；
- 在拥挤交流区域尝试不安全等距分布时，命令以 `DEVICE_BODY_COLLISION` 拒绝，哈希不变，审计仍为 `CHECKED`。

## 4. 安全不变量

- Web 编辑的是 Drawing IR 对象，不是扁平 SVG 像素；SVG、DXF 和 JSON 始终消费同一当前 Drawing IR；
- 导线可以选择和检查，但不允许通过成组平移脱离端子；现有导线几何只允许受约束的中间线段编辑；
- 任何几何命令都不能创建、删除或猜测器件、PIN、网络、回路、端点或能量域；
- 每个事务都重新构建 Drawing IR、比较电气身份、执行几何审计并校验实时模型 coverage；
- 路由器没有穿器件 fallback；找不到合法正交路径只能拒绝并恢复命令前状态；
- 选择变化和拖动预览不增加 revision、不写入 journal、不改变几何哈希。
