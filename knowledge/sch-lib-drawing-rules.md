# sch_lib 绘图规则包（充电桩原理图）

## 定位

本规则包把 `sch_lib/` 中参考图反复出现的画图规律，转换为平台可执行的语义图校验、SVG 渲染审计和导出闸门。参考图是工程经验样本，不是可执行指令，也不等同于 GB/T、IEC、EN、UL 或 SAE 的符合性证明。

运行时入口为 `window.EVSE_DRAWING_SKILL`。每次生成按以下顺序调用：

1. `EVSE_ENGINE.build()` 按输入参数确定性地选取设备档位；
2. `EVSE_DESIGN.create()` 生成带设备、命名端口和边的统一工程模型（EDEM）；
3. `EVSE_DRAWING_SKILL.apply()` 校验端口、网络语义、枪回路保护、储能支路和辅助电源来源；
4. `drawPile()` 渲染带 skill/profile 元数据的 A3 SVG；
5. `auditMarkup()` 检查图幅、文控、图例、明细表、关键位号和未解析字段；
6. `finalizeDrawingAudits()` 汇总状态，`canExport()` 在阻断项存在时禁止 SVG/DXF 导出。

平台分别记录 `selectedRuleIds`（图型选中的候选规则）、`evaluatedRuleIds`（机器实际执行的规则）和 `skippedRuleIds`（仍需人工/专业复核的规则）。只有产生了明确校验结果的规则才会进入 `evaluatedRuleIds`，避免把布局指导或标准适用性误报成已自动核验。

## 已复核样本与适用范围

当前样本为 2 个 SVG：

- `sch_lib/国标60kW充电桩原理图.svg`
- `sch_lib/欧标充电桩电气原理图.svg`

两者都是储能型充电装置的多线原理图，共同呈现的结构为：电池簇 → 熔断/主接触器/预充 → 直流母线 → 双向变换设备（DC/DC 或 PCS）→ 交流侧与充电枪回路；二次侧包含 BMS/BCU、主控（VCU/CCU）、通信控制器（SECC/EVCC/OCPP）、计量、开关电源、显示与人机交互、急停与联锁。

样本可支持的图型只有一种：

- `ev-power-schematic`：充电桩一次主回路 + 二次控制/通信 + 储能支路的多线原理图。

美标 CCS1 的图面表达由同族规则外推，缺少已复核的美标样本；相关表达必须由专业人员另行确认。

## 高置信度可执行规则

- 设备必须声明命名端口，线路只能接到端口，不能接设备几何中心；
- 边必须保存 `netClass`、方向，以及电压（功率边）或协议（信号边），颜色只能辅助表达；
- AC/DC、充电直流、储能直流、辅助直流、控制与通信必须分域，跨域只能经声明的变换设备（功率模块、PCS、DC/DC、开关电源）；
- 每把充电枪必须具备独立直流快熔与正/负极直流接触器，并接入 PE；
- 每把充电枪必须有控制导引与通信回路，端子按所选标准标注；
- 直流母线必须配置绝缘监测与电流采样，且信号送至控制单元；
- 交流进线必须具备隔离、断路、浪涌保护与剩余电流监测节点；
- 每个电池簇必须经熔断、主接触器与预充单元才能并到储能母线；
- 储能母线必须经变换设备并入，不得直接搭接充电直流母线；
- 辅助 24V/12V 必须来自明确的开关电源，不得从功率母线直接取电；
- 重复支路（多枪、多电池簇）按模板实例化，设备与回路代号全项目唯一；
- 主干与支路正交布置，真实连接画连接点，几何交叉默认不连接并画跨线；
- 线路不得穿设备、文字、图例或标题栏禁区；
- 图纸保留 A3 图框、图号、修订、状态以及编制/校核/批准字段，并附图例与设备明细表。

## 不自动学习的内容

- 不因文件名含“国标/欧标/美标”就声明标准合规；
- 不复制样本中的熔断器额定值、接触器型号、线缆规格、连接器料号、厂商型号或设备数量；
- 不把 SVG 路径直接注册为 IEC 60617 / GB/T 4728 符号；
- 不把样本颜色、字号和图层名当成强制标准；
- 不允许大语言模型绕过确定性引擎直接决定拓扑、器件档位或 SVG 几何。

## 器件档位的来源边界

`js/ev-standards.js` 中的断路器、接触器、快熔、传感器、电缆、电池与变换器档位是通用标称值序列，用于让选型结果落在可复现的档位上；它们不来自参考图，也不是厂家型录或报价。所需容量超出内置序列时，引擎显式告警并要求电气专业另行选型，绝不静默按最大档位取值。

## 规则晋级流程

新增参考图先进入 `CANDIDATE`/`REFERENCE_DERIVED`。只有完成来源追溯、跨样本复核、适用图型确认、测试用例以及电气专业人员批准后，才能形成项目级 `APPROVED` 规则。规则升级必须修改版本号并保留回归测试，不能在生产环境静默改变。
